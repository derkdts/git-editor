# Git Editor

Небольшой настольный редактор файлов Git-репозиториев на Tauri. Он позволяет открыть или клонировать локальный репозиторий и редактировать его файлы, сохранять изменения и создавать локальные коммиты через простой интерфейс.

> Интерфейс и сообщения приложения сейчас преимущественно на русском языке. Приложение выполняет только локальные операции и не отправляет содержимое репозитория или файлов на сервер.

## Возможности сейчас

- Открытие существующего репозитория и инициализация Git в выбранной папке.
- Клонирование репозитория по HTTPS, HTTP, SSH или адресу `git@host:path` в пустую папку.
- Просмотр файлов репозитория в раскрывающемся дереве папок, включая вложенные директории, с отметками изменённых (`M`) и неотслеживаемых (`U`) файлов.
- Создание файла в корне репозитория, редактирование его текста и сохранение на диск.
- Сохранение изменений в локальный Git-коммит кнопкой «Сохранить локально».
- Просмотр до 20 последних коммитов и чтение версии выбранного файла из коммита в отдельной панели только для чтения.
- Отображение текущей ветки и состояния сохранения; предупреждение перед потерей несохранённых изменений.

## Как устроено

- **Интерфейс:** `index.html` содержит HTML-разметку, стили и основной JavaScript-код приложения. Он строит раскрывающееся дерево на основе рекурсивно полученного списка файлов и обращается к командам Tauri через `window.__TAURI__.core.invoke`.
- **Мост типов:** `src/tauriBridge.ts` описывает типы состояния репозитория и обёртки для вызовов команд Tauri.
- **Backend:** `src-tauri/src/lib.rs` регистрирует команды; `fs_ops.rs` реализует операции с файлами и репозиториями; `git_ops.rs` выполняет операции Git.
- **Вызовы Git:** команды выполняются в выбранной папке через системный исполняемый файл `git`. Блокирующие операции выполняются в рабочем потоке, чтобы интерфейс оставался отзывчивым.
- **Конфигурация:** `src-tauri/tauri.conf.json` задаёт настройки приложения и `frontendDist: "../dist"`; Rust-зависимости указаны в `src-tauri/Cargo.toml`.

### Ограничения текущей версии

- Скрытые файлы и папки (имена начинаются с `.`) не отображаются; пустые директории не попадают в дерево.
- Кнопка «Новый файл» создаёт файлы только в корне репозитория.
- Редактор — обычное текстовое поле без подсветки синтаксиса и встроенного построчного diff.
- Кнопка сохранения делает локальный коммит всех изменений репозитория (`git add --all`), а не только открытого файла.
- Нет операций push/pull и управления удалёнными репозиториями или ветками.
- Для сборки интерфейса конфигурация Tauri ожидает каталог `dist`, но в корневом `package.json` пока нет скрипта сборки, а сгенерированный результат нужно размещать вручную.

## Запуск и разработка

Требуются Node.js с npm, Rust с Cargo, системные зависимости Tauri 2 для вашей ОС и установленный Git. Для Git-операций приложение должно находить Git в `PATH`.

После настройки расположения фронтенда, чтобы оно соответствовало `frontendDist` в `src-tauri/tauri.conf.json`:

```sh
npm install
npm run tauri dev
```

Скрипт `tauri` в `package.json` передаёт аргументы CLI Tauri. Сейчас автоматический `beforeDevCommand` и скрипты сборки фронтенда не настроены.

---

Не реализованные идеи:

1. **Навигация по всему репозиторию:** создание файлов в выбранной директории и переход к папкам.
2. **Удобный редактор:** подсветка синтаксиса, номера строк, поиск/замена, горячие клавиши и выбор кодировки.
3. **Настоящее сравнение изменений:** построчный diff рабочего файла с `HEAD` и выбранным коммитом, с подсветкой добавленных и удалённых строк.
4. **Контроль коммитов:** ввод сообщения, выбор файлов для коммита, просмотр diff перед подтверждением и настройка автора коммитов.
5. **Работа с ветками и remote:** создание/переключение веток, просмотр удалённых репозиториев, fetch, pull и push с понятными статусами и ошибками.
6. **Безопасность и устойчивость:** автосохранение или восстановление черновика, подтверждение перед опасными операциями, проверка путей репозитория и безопасная работа с недоверенными репозиториями.
7. **Сборка и релизы:** настроить единый frontend build pipeline, команды разработки и сборки для ОС, а также автоматическое управление версиями и пакетирование.

## Структура проекта

```text
.
├── index.html
├── package.json
├── src/
│   └── tauriBridge.ts
└── src-tauri/
    ├── Cargo.toml
    ├── tauri.conf.json
    └── src/
        ├── fs_ops.rs       # файлы, открытие/инициализация/клонирование репозитория
        ├── git_ops.rs      # Git-статус, история и локальные коммиты
        ├── lib.rs          # регистрация команд Tauri
        └── models.rs       # структуры данных
```
